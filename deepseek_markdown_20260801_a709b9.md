# Solitaire Finz Mart - Legal Evaluation Report Backend

## 🚀 Features

- Lead management with auto-population
- Legal report CRUD operations
- Document upload (PDF, JPEG, PNG)
- Admin review workflow
- MongoDB database integration
- RESTful API

## 📋 Prerequisites

- Node.js (v14+)
- MongoDB (v4+)
- npm or yarn
